Fallout: Lonesome Road

Fallout: Lonesome Road is a text-based Fallout game played in the terminal. The game started out as my friend and I's AP CSP Create Task. We wrote the game in Javascript as that was what we were learning, but we realized the game needed a much better language. As we moved on I started rewriting it in various languages, eventually landing on Java. Still maybe not ideal, but I don't know. I have since worked on it intermittently, and use it more as a tool to learn Java. As I work on it I try to make the engine its own thing as well, so that I could later make another game in it if I so choose.

Laser Scouter

Laser Scouter is an FRC Scouting App. I do like to say it was developed by my FRC team (2077) as it has its name and all, but I did do all of the development. It was my first project using Flutter and I really underestimated my skill level. As a result to get it done I relied a lot on ai for help creating the code. I do not like this at all looking back and suggest that no one use it, and I have since privated the repo. It is certainly capable but not for high-level scouting. Find something better to suit your scouting needs.

Laser Proxy

Laser Proxy was a simple project that did a lot of things for me. It was just a simple python script that would forward API requests from Laser Scouter to the Blue Alliance API. Why? Because I thought shipping my API key with an app was a bad idea. The more interesting part was the setup I had to it. For it I created a simple bash script to pull the script and install it into standard linux directories like /opt. It would also install a Systemd service file to manage the starting and stopping of the script. Along with Laser Scouter I have also privated this repo.

Global Whitelist Floodgate Patch

I try to keep my Minecraft Servers as open as possible. Part of that is because I like having new people, but the other part of that is because it was a pain to manage a whitelist across the server network. Unfortunately Velocity did not support whitelist, and most of the plugins I found handled it in some weird way. However I came across Global Whitelist by UrAvgCode. It worked great but did not support the whitelisting of Bedrock players connecting through Geyser/Floodgate. I took it upon myself to patch support in for this. It was pretty easy all things considered. But was the first time I had to look at someones code and understand it before editing it. Not only that but it was also Minecraft Plugin code which I was also not familiar with.
